# Variant A: Sharp on Top

**Thesis:** Every post is two cards, the line you wrote and the line that stops the scroll; the sharp one goes on top, with the receipt stapled to it.

**Hero:** "They read one line. / Make it *hookworthy*." Below it, a live stack: the soft draft with amber squiggles behind, the sharpened post in front in real network chrome, and a receipt that names the move. It cycles the four real rewrites.

**Palette + type:** Current brand: dark #0B0C10, an ultramarine fill, amber for soft words, green for kept facts. Newsreader with an italic punchline, Inter, Geist Mono.

**Not a clone:** No centered headline over a screenshot, no bento, no testimonials. The hero is the before/after/receipt, which only Hookworthy has.

**Trade-offs:** The tall stack puts the receipt at the fold. The sticky feature index is a familiar pattern.
