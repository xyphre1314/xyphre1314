# Feed

**Layout:** Timeline homepage.

**Idea:** The homepage is a timeline. A left rail holds the sections, an X-dark feed column holds each section as a post, and a right rail keeps the CTA, the examples and "Posts to" in view.

**Scroll story**
- Pinned post: the H1, with the sharpen playing in it.
- Compose box = the Try box. Your line lands below as a new post.
- App previews post (X thread).
- Thread from 11 PM to 8:40 AM.
- Reply chain, then results as notifications.
- "People like you" module.
- Studio: quoted client post, reply, Approve.
- Trust, then pricing as a pinned card.
- Reply box that sharpens live.
- Phones: the feed column alone, with a tab bar holding the CTA.

**Mobbin:** Better Stack, Clay, Circle, Fibery.

**Weakest point:** On desktop everything sits in a 680px column, so the product never gets a wide, cinematic moment.
