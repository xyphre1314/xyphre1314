# Combo: Sharp on Top, creator pass

**Hero:** "They read one line. / Make it *hookworthy*." beside an X-style compose box. The fluff is squiggled, Sharpen gets tapped, the blue pencil strikes the fluff in reading order, and the post lands in the feed by about 1.5s. Under it, one human line: "Why it hits: $10k stops the scroll. 3 years makes it believable." The finished state is the HTML.

**Feels like X:** compose, posts, threads, replies and notifications on X's black, hairlines and greys. The page, buttons and headlines stay ours: ultramarine, Newsreader, amber squiggle for fluff, blue rule for sharp.

**No dev talk:** no receipt tables, word counts or limit counters. Engine moves are mapped to plain phrases. Mono is used only for times.

**Live:** the Try box and the final input run the real `core.js`.

**Phone:** H1 44 / H2 32, a sticky bar, 10.9 screens.
